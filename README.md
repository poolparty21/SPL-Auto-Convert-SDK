# SPL Auto-Convert SDK

Automatic SOL to USDT conversion on Solana. Built for [savingswallet.online](https://savingswallet.online).

## Packages

| Package | Description |
|---------|-------------|
| [`@kololabs/core`](packages/core) | Core types, encryption, Solana helpers |
| [`@kololabs/gas`](packages/gas) | Gas estimation utilities |
| [`@kololabs/router`](packages/router) | Jupiter DEX routing |
| [`@kololabs/listener`](packages/listener) | Helius webhook listener |

## Usage

```bash
pnpm install
pnpm build
pnpm test
```
